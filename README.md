# موقع مركز مندور الطبي — Mandour Medical Center

موقع ثابت (Static HTML/CSS/JS) لا يحتاج أي عملية بناء (Build) — جاهز للرفع مباشرة.

## الملفات
```
mandour-medical-center/
├── index.html                 الصفحة الرئيسية (كل الأقسام) — التصميم والتفاعل مضمّنان داخل الملف
├── dental-center.html         صفحة مركز الأسنان
├── dr-khaled-mansour.html     ملف د. خالد منصور (ببيانات حقيقية)
├── specialty-template.html    قالب TEMPLATE لأي تخصص جديد (انسخه وعدّل)
├── doctor-template.html       قالب TEMPLATE لملف طبيب جديد (انسخه وعدّل)
├── articles.html              صفحة المقالات (نموذجية)
└── assets/                    اللوجو، صورة المبنى، صور التقييمات، صورة د. خالد
```

**ملحوظة مهمة:** كل صفحة أصبحت الآن ملفًا واحدًا مستقلًا يحتوي التصميم (CSS) والتفاعل (JS) بداخله مباشرة — لم يعد هناك مجلد `css/` أو `js/` منفصل. هذا يمنع مشكلة "الموقع يظهر بدون تنسيق" التي تحدث عادةً لو انفصل مجلد فرعي عن باقي الملفات أثناء الرفع اليدوي على GitHub. المجلد الوحيد المتبقي الذي **يجب** رفعه بجانب الملفات هو `assets/` (لأنه يحتوي الصور الحقيقية).

## إذا ظهر الموقع بدون تنسيق (نص عادي فقط)
هذا يعني أن أحد الملفات لم يُرفع بشكل صحيح. تحقق من:
1. افتح الـ Repository على GitHub.com وتأكد أن `index.html` ومجلد `assets/` موجودان في نفس المستوى (مش جوه مجلد فرعي زيادة باسم `mandour-medical-center` مكرر).
2. لو لقيت مجلد باسم `mandour-medical-center` جوه الـ Repository نفسه، يبقى الرفع اتعمل مرة زيادة بالغلط — امسح المجلد الداخلي وارفع محتوياته مباشرة في جذر الـ Repository.
3. جرّب تفتح رابط صورة مباشرة للتأكد، مثل:
   `https://<username>.github.io/mandour-medical-center/assets/logo-icon.png`
   لو ظهر "404" يبقى مجلد `assets/` لسه مش مرفوع صح.
4. أسهل طريقة صحيحة للرفع: من صفحة الـ Repository اضغط **Add file → Upload files**، وبعدين اسحب (Drag & Drop) **كل الملفات ومجلد assets كامل مرة واحدة** من نافذة الملفات على جهازك مباشرة إلى صفحة الرفع (السحب بيحافظ على تركيب المجلدات، أما اختيار الملفات يدويًا بيفصلها أحيانًا).

## رفع الموقع على GitHub Pages
1. أنشئ Repository جديد على GitHub، مثلاً باسم `mandour-medical-center`.
2. ارفع كل الملفات ومجلد `assets/` كما هي، في **جذر الـ Repository مباشرة** (مش جوه أي مجلد فرعي إضافي).
3. من إعدادات الـ Repository: **Settings → Pages → Branch: main → root** ثم Save.
4. بعد دقيقة أو دقيقتين سيكون الموقع متاحًا على رابط مثل:
   `https://<username>.github.io/mandour-medical-center/`

## ما يجب استكماله قبل النشر النهائي
كل نص بين قوسين `[ ]` (إن وُجد) يجب استبداله ببيانات حقيقية إضافية:
- بيانات وصور باقي الأطباء الـ82 (البطاقات النموذجية المتبقية في قسم "الأطباء").
- صورة عيادة الأسنان (وعدتم بإرسالها — أضيفوها في `assets/dental-clinic.jpg` واربطوها في قسم "مركز الأسنان" بصفحة `dental-center.html`).
- مواعيد العمل الفعلية للمركز (لا تزال Placeholder في قسم "تواصل معنا").
- تفاصيل كل تخصص من الـ25 تخصصًا (يمكن استخدام `specialty-template.html` تباعًا لإنشاء صفحة مستقلة لأي تخصص يستحق تفصيلاً أكبر).

## لوحة الإدارة (CMS)
هذا الإصدار موقع ثابت بدون لوحة إدارة مدمجة، حتى يسهل رفعه فورًا على GitHub. لإضافة إدارة سهلة للمحتوى (الأطباء، التخصصات، المقالات، التأمين) دون الحاجة لمبرمج في كل تعديل، الخيارات المتاحة لاحقًا:
- ربط الموقع بـ Headless CMS (مثل Netlify CMS / Decap CMS) يعمل فوق نفس ملفات GitHub مباشرة.
- تحويل المشروع إلى موقع مبني بـ Next.js أو مشابه مع لوحة إدارة مخصصة.
